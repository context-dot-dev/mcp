# README artwork

The banner was designed and exported in [Paper](https://app.paper.design/file/01M6ZBHNGGBJY92Y2W43QZAPBM). Access to the editable design depends on the Paper workspace's sharing settings.

- **Artboard:** Context MCP — README hero, 1600 × 800.
- **Export:** `context-mcp-hero.png`, 3200 × 1600 PNG, using Paper's default 2× export.
- **Brand:** Context.dev's official wordmark and symbol, blue `#2563eb`, white, black, and neutral gray.
- **Typography:** Rethink Sans, with a 100 px display headline on the design artboard.

The PNG is stored in this repository, so the README does not depend on Paper or a third-party image host to display it. The README repeats the key information as text and provides descriptive image alt text.
